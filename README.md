# Pokémon Explorer

Pokémon Explorer is a React application that allows users to search and filter through a list of Pokémon fetched from the [PokeAPI](https://pokeapi.co/). The application displays Pokémon in a card layout with their name, image, ID, and types. Users can search Pokémon by name and filter them by type.

---

## Features

- **Data Fetching**: Fetches the first 150 Pokémon from the PokeAPI.
- **Search Functionality**: Real-time search to filter Pokémon by name.
- **Filter by Type**: Dropdown to filter Pokémon by their type (e.g., Fire, Water, Grass).
- **Responsive Design**: Works seamlessly on both desktop and mobile devices.
- **Dark Theme**: A sleek black-themed UI with hover animations and effects.
